# نظام مصنع الأسياح للمنظفات الصناعية (Al-Asyah Detergent Factory ERP)
### نظام تخطيط موارد المؤسسات المتكامل المتوافق مع هيئة الزكاة والضريبة والجمارك (ZATCA Phase 1)

نظام ERP صناعي شامل ومتخصص في صناعة المنظفات الكيميائية بالمملكة العربية السعودية، مبني وفق أحدث المعايير البرمجية والأمنية: **Cloudflare Pages (Static SPA)** مع **Supabase (PostgreSQL, Row Level Security, Edge Functions, Auth)**.

---

## 🏗️ البنية التحتية والتقنيات (Architecture & Stack)

- **الواجهة الأمامية (Frontend):** React 18, TypeScript, Vite, Tailwind CSS, Radix UI, TanStack Query (React Query v5), Lucide Icons, Sonner.
- **التصميم وتجربة المستخدم (UI/UX):** نمط التصميم الصناعي المتجاوب (Material Design 3 M3 Expressive) مع دعم كامل للغتين (العربية RTL والإنجليزية LTR) عبر `i18next`.
- **قاعدة البيانات والباك إند (Backend):** Supabase Managed PostgreSQL مع تفعيل أمان الصفوف الصارم (RLS - Row Level Security) لجميع الجداول.
- **إدارة المستخدمين والصلاحيات (Auth & RBAC):** Edge Function مخصصة (`manage-users`) مبنية على بيئة Deno للتحكم الحصري للمدير العام.
- **الفوترة الإلكترونية (ZATCA E-Invoicing):** تشفير Tag-Length-Value (TLV) Base64 لرموز الاستجابة السريعة (QR Codes) المتوافقة مع معايير هيئة الزكاة والضريبة والجمارك السعودية (المرحلة الأولى).

## 📦 حزم ومراحل النظام (System Modules & Phases)

### 1. المرحلة الأولى: التأسيس وإدارة المنشأة (Foundation & Factory Administration)
- تسجيل الدخول الحصري برقم الجوال السعودي وكلمة المرور المشفرة مع توجيه ذكي حسب الصلاحية.
- إدارة إعدادات المصنع، السجل التجاري، العنوان الوطني، وشعار المنشأة المعتمد.
- دليل شجرة الحسابات (COA) المتوافق مع الدليل الموحد السعودي (1101 للصندوق، 1102 للبنوك، 1110 للعملاء، 2101 للموردين، 113x للمخزون، 4101 للمبيعات، 5101 لتكلفة المبيعات، 6107 لعجز الجرد).
- الفترات المالية والإقفال الشهري لمنع التعديل بأثر رجعي.
- سجل رقابي وأمني شامل لكافة العمليات الحساسة (`audit_logs`).

### 2. المرحلة الثانية: المخزون، الشراء وطبقات FIFO الصارمة (Inventory, Procurement & FIFO)
- إدارة مستودعات المواد الخام (`raw_materials`)، مستودعات التعبئة (`packaging`)، ومستودعات المنتجات التامة (`finished_goods`).
- استلام المشتريات بالوزن الفعلي بالميزان (Actual Scale Weight in KG) مع التحويل التلقائي للجرامات وتوليد طبقات الـ FIFO آلياً.
- معالجة سندات استلام المشتريات (GRN) وإشعارات المدين والتعويض (Debit Notes & Compensation) مع الموردين.
- إثبات الأرصدة الافتتاحية للمخزون مع إنشاء قيود اليومية المتوازنة.

### 3. المرحلة الثالثة: التصنيع، تركيبات الخلط وبوابة الجودة (Manufacturing & QC Gate)
- إدارة تركيبات الخلط الصناعية (BOM) واحتساب الكثافة والوزن النوعي للمنظفات.
- دورة حياة تانكات الخلط: `empty` ➔ `mixing` ➔ `pending_qc` ➔ `ready_for_packaging` ➔ `rework`.
- بوابة رقابة الجودة (QC Gate): فحص درجات الحموضة (pH)، اللزوجة (Viscosity)، اللون والرائحة ومنع التعبئة دون اعتماد مخبري.
- أوامر التعبئة والتغليف متعددة الأحجام وحساب الهالك الصناعي في العبوات والملصقات والكراتين.
- طباعة ملصقات الباركود الحرارية لتشغيلات الإنتاج (Thermal Batch Barcode Labels).

### 4. المرحلة الرابعة: المبيعات، الفوترة وعهد سيارات التوزيع (Sales, ZATCA & Delivery Vans)
- دليل العملاء مع السقوف الائتمانية وفترات السداد وإشعارات التجاوز.
- إصدار فواتير المبيعات الضريبية مع خصم الدفعات المقدمة (العربونات) وحساب الضريبة (15%).
- حارس هامش الربح الحي (Gross Margin Guard) لمنع البيع بأقل من تكلفة الـ FIFO الصناعية.
- إدارة عهد سيارات التوزيع المتنقلة (Sales Vans Custody - 1135) وسندات التحميل والإرجاع.
- احتساب وترحيل عمولات المناديب التلقائية (2%)، ومشاركة الفواتير المعتمدة عبر تطبيق واتساب بنقرة واحدة.

### 5. المرحلة الخامسة: المحاسبة العامة والرواتب والتقارير التنفيذية (General Ledger, Payroll & Analytics)
- قيود اليومية العامة المزدوجة المتوازنة وسندات القبض والصرف والشيكات البنكية.
- معالج الإقفال المالي السنوي وترحيل الأرباح والخسائر لحساب الأرباح المبقاة (`3201`).
- مسيرات الرواتب الشهرية مع استقطاعات التأمينات الاجتماعية (GOSI) وسُلف الموظفين.
- سجل الأصول الثابتة واحتساب الإهلاك الخطي الشهري الآلي.
- التقارير المالية الخمسة الكبرى:
  1. ميزان المراجعة (Trial Balance)
  2. قائمة الدخل (Income Statement)
  3. الميزانية العمومية (Balance Sheet)
  4. الإقرار الضريبي لهيئة الزكاة (VAT Declaration)
  5. التقارير التحليلية الخمسة للمدير العام (Director Analytics)

### 6. نظام الجرد الفعلي ومركز الاعتمادات (Stocktaking & Approvals Center)
- **الجرد الأعمى (Blind Stocktaking):** إخفاء كميات النظام عن استمارات العد الميداني لمنع الانحياز التأكيدي.
- **التسوية الفورية وقيد العجز `6107`:** مطابقة الفروقات الدفترية مقابل الفعلية وإنشاء قيد يومية متوازن آلياً يحمل العجز على حساب عجز الجرد المخزني `6107`.
- **مركز الاعتمادات الإدارية (`/approvals`):** شاشة حصرية للمدير العام للموافقة أو الرفض المسبب لأوامر الشراء، تجاوزات السقوف الائتمانية، والقيود اليدوية.

### 7. البوابات الميدانية المتجاوبة للهواتف (Mobile Responsive Shells)
- **بوابة صالة الإنتاج (`/production`):** للمشرفين لمتابعة التانكات، تسجيل الفحص المخبري، وأوامر التعبئة.
- **بوابة المستودع الميدانية (`/warehouse`):** لأمناء المستودع للاستلام بالميزان، صرف الخامات، وتحميل السيارات.
- **بوابة المندوب الميداني (`/rep`):** لمندوبي المبيعات لاستعراض عهدة السيارة، العملاء، وإصدار فواتير بيع ميدانية متكاملة ومشاركتها عبر واتساب.

## 🚀 التشغيل والتطوير المحلي (Local Development)

### المتطلبات الأساسية
- Node.js (v18 أو أعلى)
- npm أو pnpm

### خطوات التثبيت والتشغيل
```bash
# 1. استنساخ المستودع
git clone https://github.com/alasyahfactory/alasyahfactory.git
cd alasyahfactory

# 2. تثبيت الحزم البرمجية
npm install

# 3. إعداد متغيرات البيئة
cp .env.example .env
# تأكد من ملء VITE_SUPABASE_URL و VITE_SUPABASE_ANON_KEY في ملف .env

# 4. تشغيل خادم التطوير المحلي
npm run dev

# 5. بناء المشروع للإنتاج (Production Build)
npm run build
```

## 🔒 الصلاحيات والأدوار في النظام (Roles & Access Matrix)

| الدور | المسار الافتراضي | الصلاحيات الأساسية |
|---|---|---|
| **المدير العام (`owner`)** | `/` | وصول كامل لكافة الشاشات، مركز الاعتمادات، إعدادات المصنع، الإقفال السنوي، والتحليلات التنفيذية |

| **مشرف الإنتاج (`production`)** | `/production` | صالة الإنتاج، تانكات الخلط، بوابة الجودة QC، مواصفات التعبئة، والملصقات الحرارية |

| **مندوب المبيعات (`sales_rep`)** | `/rep` | عهدة السيارة المتنقلة، دليل العملاء، إصدار فواتير البيع الميدانية، والعمولات المستحقة |
